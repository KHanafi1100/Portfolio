# Khaled Hanafi — Portfolio

Professional software development portfolio featuring a News Retrieval-Augmented Generation project, education, technical skills, contact links, and a downloadable résumé.

## Hosting

Public URL after deployment: https://khanafi1100.github.io/Portfolio/

The GitHub Pages workflow deploys automatically when files change on `main`. If Pages setup is required, open **Settings → Pages**, select **GitHub Actions** as the source, then run **Deploy portfolio → Run workflow** in Actions.

## Local preview

Run `python3 -m http.server 8000` from the repository and open http://localhost:8000.

## Updates

- `index.html`: content, navigation, and embedded résumé PDF.
- `styles.css`: dark theme and responsive layout.

No dependencies or build step are required. The RAG project description reflects an academic prototype and qualitative notebook experiments. Additional projects can be added later.
